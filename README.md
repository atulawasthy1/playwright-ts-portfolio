# Playwright TypeScript Automation Framework

A scalable test automation framework built with Playwright and TypeScript for Web UI and API testing.

## Project Status

🚧 Framework development in progress

The project foundation is complete, including:

- Playwright Test with TypeScript
- Chromium browser execution
- Strict TypeScript configuration
- HTML test reporting
- Scalable UI and API folder structure
- Git version control and GitHub repository setup

## Tech Stack

- Playwright
- TypeScript
- Node.js
- npm
- Git and GitHub
