# CLAUDE.md

## Purpose

This repository uses `AGENTS.md` as the primary engineering guide.

Always read and follow `AGENTS.md` before making changes to the project.

## Development Rules

- Treat `AGENTS.md` as the single source of truth for engineering decisions.
- Do not duplicate rules already defined in `AGENTS.md`.
- Follow the existing project architecture and coding standards.
- Prefer small, safe, and reviewable changes.
- Reuse existing abstractions before introducing new ones.
- Keep commits focused and meaningful.
- Keep documentation aligned with the implementation.

## Priority Order

1. AGENTS.md
2. Project source code
3. README.md
4. User instructions for the current task

If there is a conflict, follow the highest priority item.
